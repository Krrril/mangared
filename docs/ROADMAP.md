# ROADMAP.md — MangaRed

Амбиции из исходного мастер-плана (30 потенциальных глав: Backend, Admin
Panel, AI, Recommendation System, Notifications, Sync, Offline, Security,
SEO, Analytics, монетизация и т.д.) распределены здесь по фазам. Ничего
не потеряно — просто не всё делается одновременно.

## MVP — сквозной продукт на реальных данных

Цель: работающее приложение, которое выглядит и ощущается как финальный
продукт, без собственного бэкенда — контент идёт напрямую из MangaDex API.

- [x] Настроить проект (Vite + React, структура из ARCHITECTURE.md)
- [x] Дизайн-токены из DESIGN_SYSTEM.md (CSS-переменные, шрифт, иконки)
- [x] Layout веб-версии: сайдбар + топбар + правая панель
- [x] Главная страница: hero-баннер, "Популярное сегодня", "Продолжить
      чтение", категории, "Новинки" — на реальных данных MangaDex
- [x] Страница тайтла: обложка, описание, рейтинг, список глав — реальные
- [x] Читалка: постраничный + вертикальный просмотр, яркость, направление —
      реальные страницы глав с MangaDex, запрашиваются при открытии
- [x] Поиск по названию/автору и по жанру — работает через глобальное поле
      в топбаре (debounce → `/search?q=...` → MangaDex) и через страницу
      "Категории" (`/search?genre=...`), состояния "введите запрос" и
      "ничего не найдено"
- [x] Категории — страница со всеми жанровыми тегами MangaDex, чипы на
      главной и там кликабельны
- [x] Топ манги — список, отсортированный MangaDex по рейтингу
- [x] Библиотека — список тайтлов с сохранённым прогрессом чтения
      (честный MVP-скоуп без аккаунтов: это и есть "моя коллекция")
- [x] Избранное — localStorage (services/favorites), кнопка-сердце на
      странице тайтла реально добавляет/убирает
- [x] История — полный список прогресса чтения, кнопка "Открыть всю
      историю" в правой панели теперь ведёт туда
- [x] Обновления — отдельная страница с более длинной лентой (переиспользует
      getUpdatesFeed и компонент UpdateRow из правой панели)
- [x] Прогресс чтения — сохранение в localStorage, без бэкенда
- [x] Реальные обложки с MangaDex, градиент — только резервный fallback
      (см. DESIGN_SYSTEM.md §7)
- [x] Адаптер контента (services/content) — теперь на MangaDex API
      (см. src/api/mangadex, ARCHITECTURE.md)
- [x] Мультиязычный интерфейс: ru + en полностью, ещё 8 языков —
      рабочие заготовки (см. DECISIONS.md)
- [x] Обработка лицензированных ("внешних") глав — ссылка на официальный
      сайт вместо чтения в приложении
- [x] Атрибуция MangaDex и групп сканлейта в интерфейсе (требование ToS)

## Не по фазам, а по мере надобности

Полноценный брендинг (лого, философия, tone of voice) — самостоятельная
задача, которую можно делать параллельно с любой фазой, как только
появится время/желание. Название уже зафиксировано — **MangaRed**
(см. DECISIONS.md), остальное (лого, тон общения) — бэклог.
